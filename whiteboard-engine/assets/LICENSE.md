Remote icon licenses remain with their providers: Lucide uses ISC; Tabler and
Phosphor use MIT. Iconify is a delivery service, not a blanket license for all
icon sets. Downloaded source URLs and license names are recorded next to cached
SVGs and in each video's render manifest. For redistributed remote collections,
include the upstream license and copyright notices.

SVG Repo and Public Domain Vectors assets are only fetched when you explicitly
register a direct SVG URL and its verified license in `asset_manifest.json`.
No assumption is made that everything on a vector aggregation site is CC0.

Fonts use the SIL Open Font License 1.1. Setup downloads the corresponding
upstream license text into `fonts/` alongside each font family.
